# GDevelop Product Overview

GDevelop is a full-featured, open-source, no-code game development software. It enables users to build 2D, 3D, and multiplayer games for mobile (iOS, Android), desktop, and the web using an intuitive event-based system and modular behaviors.

## Key Features

- **No-code development**: Visual event-based programming system
- **Multi-platform export**: Games run on iOS, Android, desktop, and web browsers
- **2D and 3D support**: Built-in rendering engines for both dimensions
- **Extension system**: Modular architecture with behaviors, objects, and effects
- **AI assistance**: Built-in AI tools for game creation

## Target Users

- Game developers of all skill levels
- Educators and students learning game development
- Indie developers and small teams
- Hobbyists creating games without programming knowledge
